# Daily Record Management System

A Python-based desktop application designed for mid-scale dairy companies to efficiently track and manage daily records. The application provides a simple interface for data entry, storage, and visualization, ensuring smooth operations and insightful analysis.

---

## Features

- **Executable Release**: Ready-to-use `.exe` file available in the Releases section for quick deployment without requiring Python installation.  
- **Record Tracking**: Maintain daily records of production, sales, and inventory.  
- **Graphical Representation**: Visualize trends and performance through built-in graph generation.  
- **User-Friendly Interface**: Intuitive design for ease of use by staff with minimal technical background.  
- **Local Storage**: Data stored securely on the local machine, ensuring privacy and reliability.  

---

## Installation

1. Navigate to the **Releases** section of this repository.  
2. Download the latest `.exe` file.  
3. Run the executable to launch the application.  
4. No additional setup or dependencies are required and PASSWORD IS 12345.  

---

## Usage

1. Open the application via the `.exe` file.  
2. Enter daily records (production, sales, etc.) into the provided fields.  
3. Save entries to maintain a continuous log.  
4. Use the **Graph View** option to analyze data trends and performance.  

---

## Technology Stack

- **Language**: Python  
- **Libraries**:  
  - Tkinter (GUI)  
  - Matplotlib (Graph generation)  
  - SQLite (Local database)
